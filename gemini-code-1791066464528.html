Technical Architecture & Stack Breakdown

1. Data Engineering & Storage

  • Source Ingestion: Python pipeline reading federal procurement logs with header detection.
  • Relational DB: PostgreSQL star schema (`dim_party`, `dim_discipline`, `fact_rfi`).
  • Lakehouse Architecture: Databricks Bronze, Silver, and Gold Delta tables.

2. Analytics & BI Reporting

  • Executive Overview: Status distributions, response rates, and submitter trends.
  • Engineering Deep-Dive: Breakdown by system (BESS, Natural Gas, SCADA).
  • Document Control Impact: Tracking drawing and specification amendment requirements.

3. AI Models & Model Registry

  • Discipline Classifier: TF-IDF / embeddings predicting technical discipline.
  • Document Impact Model: Predicts drawing & spec update triggers from free text.
  • Experiment Tracking: Parameter logging and registration through MLflow.

4. Generative AI & Semantic Copilot

  • Abstractive Summarisation: High-precision technical summarisation of lengthy RFIs.
  • Vector Retrieval: Semantic search indexing for non-keyword similarity lookups.
  • RFI Copilot: Structured tool-calling agent with strict grounding guardrails.
